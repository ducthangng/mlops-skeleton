# Archive: the standalone router service (retired 2026-11-18)

These results were measured on the old `router` service (`app/` in this repo, image
`ghcr.io/ducthangng/router`), before routing became a module (JJ) inside the AI gateway product
(github.com/ducthangng/custom-ai-gateway). That service, its semantic cache, rate limiter and mock LLM
no longer exist; the numbers here describe it and are kept for history only. They are NOT
measurements of the current product. Current numbers: see the main Readme.
